# Capturas de tela

Imagens referenciadas pelo [README](../../README.md). Os nomes de arquivo são
fixos: ao atualizar uma captura, mantenha o mesmo nome.

## Padrão

- Formato PNG, retrato, sempre no mesmo simulador de iPhone.
- Dados fictícios: abra o Demo com o argumento de inicialização `--mock-data`
  (Scheme → Run → Arguments). Nenhum nome, e-mail ou projeto real aparece.
- Idioma Português (Brasil). No simulador, conteúdo em outro idioma abre um
  aviso de tradução indisponível; por isso os dados fictícios estão em português.
- Barra de status limpa (9:41, bateria cheia), se possível.
